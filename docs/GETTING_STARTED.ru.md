# Начало работы с AI Command Center

[English](GETTING_STARTED.md) • [Русский](GETTING_STARTED.ru.md)

Добро пожаловать в **AI Command Center** — центр управления и телеметрии для мультиагентных систем **Google Antigravity** под управлением **AI Development Director**.

В этом руководстве описаны первые 5 минут работы с системой: от запуска локального окружения до мониторинга автономных субагентов, проверки 9-пунктных отчётов и анализа телеметрии в реальном времени.

---

## 1. Что такое AI Command Center?

Google Antigravity позволяет автономным ИИ-агентам разрабатывать программное обеспечение в изолированных воркспейсах. Однако по мере роста числа агентов (фронтенд, бэкенд, тестирование, безопасность, юридический комплаенс) разработчикам необходим единый пульт управления.

AI Command Center предоставляет:
- **Наблюдаемость в реальном времени**: Отслеживание сессий агентов, работающих субагентов и расхода токенов по мере их выполнения.
- **Динамический контроль параллелизма**: Безопасное ограничение числа параллельных субагентов (до 6 потоков) для предотвращения переполнения памяти и лимитов API.
- **Многоступенчатые шлюзы качества**: Контроль приёмки задач (Gate 1 — тесты и линтеры, Gate 2 — независимое ревью, Gate 2b — юридический комплаенс РФ и ЕС).
- **Изолированная эскалация к Gemini 4 Argon (L4)**: Автоматическая фиксация тупиков (лимит в 2 попытки) и подготовка 18-пунктных пакетов воспроизведения с очисткой путей и секретов.

## 2. Быстрый запуск за 5 минут

### Шаг 1: Запуск сервисов
Откройте терминал и перейдите в папку проекта:

```bash
cd d:\Projects\ai-command-center
npm run dev
```

Либо в Windows просто дважды кликните по [`start.cmd`](../start.cmd) или используйте [`setup.cmd`](../setup.cmd) для установки в 1 клик.

В терминале отобразится:
```text
[AI COMMAND CENTER] Server running on http://127.0.0.1:3001
[AI COMMAND CENTER] WebSocket stream at ws://127.0.0.1:3001/ws
[AI COMMAND CENTER] Antigravity dir: C:\Users\<user>\.gemini\antigravity
[AI COMMAND CENTER] Knowledge dir:   C:\Users\<user>\.gemini\antigravity\knowledge\ai-director
VITE v8.3.5 ready in 250 ms
➜  Local:   http://localhost:5173/
```

### Шаг 2: Открытие панели управления
Откройте веб-браузер и перейдите по адресу:
**[http://127.0.0.1:5173](http://127.0.0.1:5173)**

Откроется панель управления в эстетике **Refero / Vercel** (с поддержкой светлой темы Paper White и тёмной темы Obsidian Black) со статусом подключения **ONLINE**.

## 3. Обзор разделов панели управления

Телеметрия мультиагентной системы разделена на 8 основных разделов:

### 1. Mission Control (Обзор)
Главный кокпит состояния системы:
- **Статус Директора**: Версия модели (`Gemini 3.8 Flash High`), активные сессии и блокировки файлов.
- **KPI-метрики**: Число работающих субагентов, завершённых задач, процент успешности и суммарный расход токенов.
- **Лента событий**: Потоковая трансляция запусков агентов, прохождения шлюзов качества и завершения этапов.
- **Кнопка «1-Click Setup»**: Моментальная синхронизация всех 17 агентов в директорию Antigravity.

### 2. Пул специалистов (Агенты)
Интерактивная сетка 17 канонических ролей:
- Просмотр статуса (`idle`, `running`, `blocked`, `escalated`) каждого специалиста.
- Изучение системных промптов и регламентов прямо из `~/.gemini/config/plugins/ai-director/agents/*.md`.
- Контроль процента успешности и количества запусков по каждому агенту.
- 1-Click синхронизация с Antigravity.

### 3. Оркестрация (Live Workflow)
Интерактивный граф жизненного цикла задач:
- Переходы по этапам: `Director_Triage` → `Solo` / `Specialist` → `QualityGate_L1` → `Independent_L2` → `LegalGate` → `Architect_L3` → `Argon_L4` → `Approved`.
- Анимация пульсации, подсвечивающая активные задачи на каждом узле.

### 4. Аналитика моделей
Учёт расхода токенов и производительности:
- Детализация по семействам моделей: **Gemini 3.8 Flash**, **Gemini Pro (Senior Architect)** и **Gemini 4 Argon**.
- Чёткое разделение подтверждённых **LIVE** токенов из транскриптов и расчётных **ESTIMATED** значений.
- Счётчики входных, выходных и прочитанных из кэша токенов.

### 5. Диспетчер задач (Task Manager)
Оперативная доска управления задачами:
- Фильтрация по статусам, приоритетам и назначенным агентам.
- Просмотр деталей задачи, счётчиков повторов и журналов ошибок.
- Проверка строгого **9-пунктного отчёта**, который агент обязан предоставить по завершении работы.

### 6. Память Директора (Memory Explorer)
Встроенный редактор глобальной базы знаний AI Director:
- Редактирование файлов `DIRECTOR_PROTOCOL.md`, `AGENT_REGISTRY.md`, `QUALITY_GATES.md`, `FAILURE_LOG.md` прямо в браузере.
- Изменения сохраняются в `~/.gemini/antigravity/knowledge/ai-director/` с нулевой задержкой.

### 7. Центр эскалаций к Gemini 4 Argon
Панель управления тупиковыми ситуациями (Уровень 4):
- Автономное обнаружение повторяющихся сбоев, циклических блокировок и противоречий между агентами.
- Переключатель чувствительности (`conservative`, `balanced`, `aggressive`).
- Генератор 18-пунктных промпт-паков с очисткой путей и секретов и копированием в буфер одним кликом.
- Разбор вердиктов Argon и передача скорректированного плана Flash-специалистам.

### 8. Единый поток событий (Events)
Высокоскоростной журнал событий в формате JSON:
- Поток всех событий системы (`agent.*`, `task.*`, `legal_gate.*`, `escalation.*`).
- Поиск и фильтрация по типу события, ID агента и ID задачи.
- Быстрое копирование payload для отладки.
